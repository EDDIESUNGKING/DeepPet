# DeepPet V10.211 收尾驗收

## 本輪實際修改
- 額外紀錄：清空已編輯文字時不再回退到舊草稿；點選分類也不會復活已清空文字。
- 飲食：空白用餐日期不能被自動當成今日；混合餐已有草稿時，不得悄悄忽略新輸入的非法克數。
- 用藥／疫苗：新增資料的單位、接種狀態與合法值檢查。
- 應急提醒：真實日期、分鐘格式、缺失／非正數讀值檢查，缺值不當零；日期選擇增加真正日曆合法性。
- 無資料的睡眠／精力詳細頁：使用實際所選歷史日期，對應原有返回動作，不重新設計畫面。
- 解釋：高分不等同全面健康，低分不自動意味已證實的生理變化；補齊韓文恢復觀察限制；空白分數不當零；改善期間低分計數及英語單複數。
