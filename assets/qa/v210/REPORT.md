# DeepPet V10.210 — 剩餘工作研究、修正、驗收與接續紀錄

## 範圍與版本
直接接續 V10.209 原始完整工程；本機架構保留。使用者接受2–3秒啟動，不再專項優化。算法與顯示分離、外部部署、五年儲存/資料庫容量及尚未接入工廠的真實4G硬體均排除，不列入本輪工程缺陷。原有 CSS 12份、圖片246份、資料747份（本次保護分類）、核心 unified-deep.js 全部逐檔雜湊不變。未任意更改原始量測、展示資料或核心權重。基準 ZIP SHA256 見 baseline.sha256。圖表與版型設計未重做，但尚未全頁像素/語義比較。

## 實際修改（12組APP問題/改善，另1組測試工具修正）
1. 體檢嚴格數值解析：拒絕布林值、陣列、非有限數值、十六進位及不合法參考界線，不將它們轉成可計分數值。
2. 體態 BCS 只接受1–9整數與相容9分尺度；一般工程參考4–5，不假定所有個體的最佳體態。無犬貓資訊不猜測。
3. 體檢日期、身份、個體參考條件及單位防護；不相容的檢驗不能直接比對或取得分數。
4. 重複匯入同一測值去重，不重複加權；嚴重旗標與測值矛盾提示核對。
5. 不同報告的歷史趨勢僅在可確認同一檢驗機構、可比方法/單位時比較；資料不足不宣稱趨勢。
6. 體檢與健康模型：目前無可靠校準，維持融合權重0、applied=false，文字如實表達未改即時生理分數，而非假報已校正。
7. 心動時刻取單一最新有量測/評分紀錄的日期，不再將不同日數值合成；LAFA 透過已存在的canonical 日分數取值，限制分數0–100。
8. 心動時刻顯示歷史日期、來源、日評分與60秒量測區別；無有效資料時不製造新分數、倒數或即時波形，四表情與版型保留。
9. 心動時刻關閉按鈕先綁定、停止動畫並釋放舞台；過期照片載入不再重建已關閉畫面。
10. 全域基本資料防護不再攔截心動時刻關閉鍵（Lucky/New Pet）；真實瀏覽器重現、修正及驗收。
11. 既有日曆快取限制8鍵，保留正確寵物資料。版本統一10.210。
12. 四語解釋：缺靜息值使用「記錄平均」而非「靜息」；無個體基準不稱偏離平時；用實際期間分數日數及有效覆蓋描述，避免高分健康保證。
13. QA工具修正（非APP修正）：wait_for_function 返回DOM物件的持久handle，改成布林並顯式dispose，注入腳本handle亦釋放。見記憶體研究。

## 自然記憶體：定位到實際保留路徑
原先壓力腳本 wait_for_function 返回DOM節點而未dispose。50次寵物切換後，診斷性GC仍有49棵已脫離主頁。Heap snapshot 14個脫離MAIN的直接保留邊皆由DevTools Global handles持有（heap-retainers.json）；不是已證實的APP自身MAIN洩漏。修正測試工具後，同規模201操作GC後57,452→931 DOM節點，無舊MAIN，只剩NAV與onboarding兩個detached roots（仍須確認）。
- 預設Chromium heap長測，625寵物操作後主動停止，以避免共用容器4GiB上限；停止前cgroup約2.75GB，無法據此判定一般手機長壓全通過。memory-long-stop.json。
- 限制V8 old-space 192MB，測試期間依瀏覽器自身正常GC、無人工GC：1,001次寵物切換、1,000次主頁切換，另5次實際滑鼠導航，全部未記錄JS例外；每次檢查摘要/隔離，切換均<0.3秒。寵物中位0.1168、P95 0.1730、P99 0.2023、最慢0.2571秒；主頁中位0.0603、P95 0.0846、P99 0.1051、最慢0.1769秒。自然結束heap45,428,588 bytes / nodes2334；空閒後33,688,576 / nodes5284。另在測試結束後進行獨立診斷GC，heap26,291,644 bytes / nodes931，2 detached roots與之前相同；無舊MAIN。此輪早於最後僅說明文字的修改，最新文字已單元重測並進行跨語言瀏覽器回歸；不得宣稱最後版本全面自然壓力或所有長期記憶體缺陷通過。500歷史日曆及300波形壓測未完整達標。
