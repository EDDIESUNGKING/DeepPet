DeepPet V8.55 — 15 static demonstration pet pictures

This build reassigns previously generated photo-collage pet portraits to the 15 existing demo profiles by fixed score.
It is intended for visual demonstration ONLY; it does not preserve individual pets’ original photo identities or breed attributes.
All current 15 profiles now show score-matched photos in Home and Heart Moment.
No new AI generated image editing was performed in this build. Scores and health data have NOT been changed.
For each demo pet the four image-grade paths currently point to the same assigned preview photo, because the demo uses a fixed current score. DO NOT claim four distinct expressions have been produced.
For new user uploads, a live AI image generation service and GEMINI_API_KEY are still needed; no new photo auto-generation is guaranteed on static Netlify Drop.

Installation: unzip and drag whole folder containing index.html onto Netlify Drop.
