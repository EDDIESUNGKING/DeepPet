DeepPet V8.62 完整 Netlify 网站

1. 基于 V8.61 原始完整 APP：保留 Home／Deep／Health／Me、15 只宠物、New Pet、空白档案、60 秒心跳时刻、健康管理、驱虫记录等原有程序与资源。
2. 本版修改：5 页 onboarding 的背景／手机图像拆层。场景图片中不含任何文字、分页圆点或虚构手机 UI。手机画面从真正的 V8.61 APP 运行页面由 Chromium 截取，然后按需要裁切及重新排列，不重新绘制虚假界面。截图包含模拟数据，GPS 为 APP 原有离线示意地图。
3. 顺序：四只狗 → 阿拉斯加 → 金毛 → 泰迪 → 法斗。
4. 语言：英文、简体中文、繁体中文、韩文；额外保留日文。首次按浏览器/手机语言决定；APP 的手动语言偏好优先。
5. 交互：刷新/重新开启先显示第1页；手指左右滑动、鼠标拖动或点底部5个圆点切换；每次只有1个高亮圆点；第5页点击 Get Started（多语言按钮）才进入原 APP。
6. 图片：背景900×1950 WebP；真实 APP 截图860×1860 WebP。网页分开渲染文案和唯一的一组分页控制，避免之前双层重叠。
7. 部署到 Netlify Drop：解压 ZIP，将包含 index.html 的全部网站文件夹拖入 Netlify Drop；不要只上传 index.html 或仅上传图片。若通过 Git 构建，提供 netlify.toml 与 build.mjs，运行 node build.mjs 发布 dist。
8. 生产边界：这仍是模拟健康数据的演示 Web APP，GPS 是原 APP 内的示意模拟地图；云端 AI 静态表情生成功能、真实项圈 SDK 及系统推播需另行连接。网页端视觉素材中的狗狗与项圈是原有市场展示插画，并不是经 3D CAD 尺寸验证的硬件渲染。
9. 本地测试通过：四种主要语言 × 5 页；素材加载、分页点、左右滑动、进入 APP；430×930 及 375×667 视口；15 只原有宠物及 4 个主页面渲染；Netlify build；文件哈希及 ZIP。详见 QA_V862.json。
10. 本次没有在用户真实 Netlify 域名、iPhone Safari 或全部子页面逐项实际测试；请部署后完成实机验收。
