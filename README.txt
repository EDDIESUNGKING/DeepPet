DeepPet V8.54 — 全屏静态心跳时刻 + 模拟数据完整网站
====================================================
本 ZIP 是现有 DeepPet APP 的完整网页文件，而不是单独的设计图片。

直接使用：
1. 解压，确认根目录有 index.html、app.js、breed-catalog.js、styles.css、assets、build.mjs、netlify.toml。
2. 登录 https://app.netlify.com/drop ，拖放整个 DeepPet_V8_54_Netlify 文件夹或 ZIP。
3. Netlify 登录状态支持读取 netlify.toml 并执行 node build.mjs，把静态网站发布到 dist/，Functions 从 netlify/functions 打包。
4. 也可直接用浏览器打开 index.html 浏览静态功能；部分浏览器的 file:// 安全策略可能影响持久化照片和云端接口。建议在 https:// Netlify 上运行。

V8.54 与上一版的区别：
- 心跳时刻：纯静态宠物照片，不再加载任何 MP4；照片铺满整个手机屏幕；下方透明心率/呼吸实时模拟波形。
- 已有当天分数的宠物：直接显示成绩、状态、HRV 圆圈、正确分数级距的图片文件，省去 60 秒倒数。
- 首次使用的宠物：全屏图片先保持模糊；显示炫光 60 秒倒数、模拟心率/呼吸；60 秒完成后出模拟分数。
- 为避免先露出错误表情：新宠物只有在分数对应的静态表情图准备好后才去模糊清晰展示。云端服务尚未完成时会保持模糊并提示，绝不冒充已生成。
- 提供 4 种语言的心跳时刻 UI：简体中文 zh、繁体中文 zht、英语 en、韩语 ko。
- 保存按钮会导出含有指标和波形的 PNG。Safari/iOS 某些浏览器可能使用系统分享方式处理保存，未进行实机验证。
- 保留原网站全部 Home、Deep、Health、Me 及健康回顾功能相关源码和图片。

重要：照片真实性与外部条件
- 15 只示例宠物各有 4 张独立的 JPG 静态素材，合计 60 张；另外保存 15 张原图。
- 默认离线素材使用真实的原始宠物照片进行不同级距的柔和色调处理；为了不再出现眼睛、嘴巴重影，完全不使用局部五官贴片。
- 这 60 张本地示例素材 **不是** 经 AI 重新生成四种真实面部表情的照片。原始照片若张嘴，低分级距里仍可能保留原始张嘴姿态。不能将颜色处理误认为真实情绪改变。
- 若需真正的「低分闭嘴不开心、80分平稳、90分开心」图生图编辑，必须设置 Google Gemini 图片生成 API，或由设计师替换同名 JPG。
- 未来用户上传新宠物：程序包含一个 Netlify Function：netlify/functions/pet-expression.mjs，按分数生成对应静态表情图。此服务需要站点所有者在 Netlify 环境变量（Functions 范围）配置 GEMINI_API_KEY，方可运行。
- 未配置 GEMINI_API_KEY 时，新宠物可得到模拟分数、倒数、波形，但不能声称 AI 表情图已生成，系统会保留模糊照片并说明等待。
- 图片生成不是 HRV 测量本身，可能花费比 60 秒更长时间。只有在取得图片后才从模糊平滑转为清晰。
- 这是原型模拟数据，未接真实项圈 SDK。60秒倒计时不代表经临床验证的 HRV 时长。心跳/呼吸数值也只是演示，不可视为医疗判断。
- 该 Function 暂无正式用户身份验证与用量限制，上线公开付费图片 API 前必须增加登录认证、限速、预算上限、隐私政策及肖像上传授权。现在默认不启用付费 AI。
