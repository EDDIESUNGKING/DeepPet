DeepPet V8.57 — 新用戶 60 秒倒數／全屏心跳時刻

如何查看「新用戶 60 秒」畫面：
1. 解壓本 ZIP。
2. 把包含 index.html、assets、app.js、styles.css、breed-catalog.js 的整個網站資料夾拖到 Netlify Drop，或者依 netlify.toml 使用 Git 部署。
3. 網頁首頁的寵物大圖下方，點「新用戶 · 60 秒心跳倒數體驗」；直接顯示手機全屏倒數畫面。
4. 或在部署網址後加上 ?deeppet_demo=first_time 直接啟動首次體驗（不會修改寵物健康資料）。
5. 倒數 60 秒後才顯示當前示例寵物的分數與 HRV；可點左上下載 PNG、右上關閉。
6. 平常點首頁「心跳時刻」，現有 15 隻示例寵物直接顯示自己的分數，不需要倒數。
