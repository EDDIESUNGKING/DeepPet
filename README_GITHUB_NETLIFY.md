# DeepPet V10.127｜完整 GitHub / Netlify 網站

入口檔在本 ZIP **根目錄**：`index.html`。不需 npm、Vite 或額外編譯。

## 上傳部署

1. 解壓 ZIP，將裡面的 `index.html`、`assets/`、`netlify.toml`、`_redirects` 直接放入 GitHub repository 根目錄。
2. GitHub Desktop Commit、Push 後，Netlify 會依連接的 repository 自動部署。
3. Netlify 的 **Publish directory** 用 `.`，**Build command** 可留空。
4. 若看見舊版，檢查 Netlify 部署狀態、清除快取並重新整理；新版 CSS、JS 使用 `?v=10127`。

## 這版改動

- **首頁今日待辦每卡最多四行**，包括「查看全部」中的卡片。
- 深入分析**高風險最多十行、中風險六行、低風險五行、健康兩行**，適用心肺、睡眠、精力恢復主項及子項，單日／7天／30天。
- 每個深入分析分頁單日只顯示**一則**今日觀察與建議；「查看簡明詳情」可打開新頁，該頁也不超過對應行數限制。
- 解釋以最重要的**實測數字、個體參考、差異幅度**為主；危急症狀的處理建議維持明確，但不堆砌長文或誇大疾病判斷。
- 精力、睡眠、今日待辦與日期捷徑移除部分重複與英文混用。
- 不修改原有 15 隻展示寵物的資料、評分與 Lucky 接入功能。
