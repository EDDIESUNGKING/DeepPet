# DeepPet V10.231 — 寵物切換效能修訂版

本版基於 V10.230 文字修訂工程。原有CSS、三波形生成器、評分公式、權重及封存資料保持不變。30個內建非實測檔案於2026-11-28的30日摘要已由同一算法預先計算，並驗證原有歷史分數未變。切換時優先載入同日且符合個體輸入的摘要；記憶體快取上限8個。新日期使用可核對的已有摘要及背景計算，未完成的新日期不冒用歷史分數；完成後快取摘要。

## 使用
完整解壓縮，保持 index.html、assets、data 同層。可雙擊 index.html 測試；若有瀏覽器限制，可使用 `py -3 -m http.server 8775 --bind 127.0.0.1` 並開啟 `http://127.0.0.1:8775/index.html`。Netlify Base directory 和 Build command 留空，Publish directory 為 `.`，無需 npm build。

## 注意
預先計算資料僅涵蓋2026-11-28；新日期第一次完整計算仍需要時間，背景計算完成前僅顯示有來源的歷史記錄。原有實際量測不會被覆蓋，New Pet和空白檔案不使用這些摘要。網站仍包含拉菲原有私人歷史資料及頭像，不應未經授權公開上傳。正式後端權限、臨床校正、原廠20Hz硬體及實際Netlify部署仍需獨立驗證。測試工具及歷史報告不在網站包中。帶有舊版本名稱的JS/CSS是有效組件，不可直接刪除。
