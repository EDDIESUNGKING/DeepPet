DeepPet V8.71 – Preventive Heart/Breathing, HRV, Rest & Energy/Recovery
=======================================================================
部署：請將 dist/ 資料夾拖曳至 https://app.netlify.com/drop 。
本 ZIP 同時包含全部原始 HTML、JS、CSS、寵物圖片及原版五張開機圖。

版本主要變更
1. Deep「精力與活動」統一更名為「精力與恢復」（简中：精力与恢复；英文：Energy & Recovery；韓文：활력과 회복）。
2. 心肺：保留心跳、呼吸現況及即時波形入口；新增 HRV 分項 RMSSD 與 SDNN 的原始數值（ms）、白話解釋、相對個體歷史比較和預防建議。
3. 今天的 HRV 比對：至少 3 個先前有效日作為可比較參考；數值相對平均偏離 15%／25%／40% 以上分階段提示，此門檻只是 DEMO UI 規則，沒有獸醫臨床風險效度。不同量測時間與運動狀況不可直接比較。
4. 7／30 天 HRV：用期間有效日平均並對比前半段與後半段，絕不把今天的值冒充期間平均。
5. 睡眠：展示當日及期間「休息異常與心跳／呼吸變化是否同時存在」。當日夜間測試段取 00:00–08:00 和 20:00–24:00 的 DEMO 數據做比較；不等同真實跨日完整睡眠期，更不證明因果。
6. 「精力與恢復」：移除獨立的活動情況卡；保留「精力情況」與「恢復情況」，下方僅保留「放鬆與平穩度」。從介面刪去重複的「活動負荷調節」，保留舊指標計算與歷史資料以供後續驗證。
7. 恢復分數沿用原有示例邏輯，比較活動停止後的兩分鐘心率下降幅度；現有分鐘級 DEMO 數據不能代表已驗證的逐搏級恢復測試。
8. 所有 Deep 評分與提示顏色統一：≥90 綠／正常，80–89 藍／輕度留意，60–79 橘／中度留意，<60 紅／優先留意。此分類不是疾病診斷。
9. 能量／情緒：改為情緒傾向與活力觀察，不將高心率等同開心，也不將低分等同憂鬱或疾病。
10. Home、Health、Me 既有功能、資料與開機五張原圖均保留；開機圖的四語言圖片翻譯尚未處理（依先前要求最後完成）。

科學與產品邊界
- RMSSD 反映相鄰正常心搏間短期變化，SDNN 反映整段正常心搏間隔的整體變異；狗貓不能共用單一 HRV「健康數值」門檻。
- 高活動／高心率可與興奮、緊張、運動等多種情況有關，無法單靠 BCG 或 HRV 準確分辨開心與不開心。
- 需要真實 SDK 的訊號品質控制、資料比對、獸醫標註資料與獨立驗證後，才能把 DEMO 相對差異提示升級為正式風險預警。
- 呼吸困難、昏倒、極端虛弱等症狀應優先求助獸醫，不應等候 App 分數。
